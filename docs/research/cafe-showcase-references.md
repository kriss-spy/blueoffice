# Café showcase references for BlueOffice

Checked 2026-10-08. These are actual Blue Archive café screenshots, inspected visually in the browser. They are references for art direction and layout, not proof that we have the matching furniture assets.

The user subsequently selected a modern open office with computer workstations and an actual café bar. [Their supplied recording capture](../references/modern-office/START-HERE.md) now leads the workstation reference. The library below suits an optional independent secretary office; the classroom is a deferred alternate world. These older examples do not determine the default room style.

## Office / study composition

Creator: calice. [Café construction guide, example 1](https://note.com/calicenon/n/n8f9b1f8ef599), published 2025-06-15.

![Library and study-style café](https://assets.st-note.com/production/uploads/images/196114980/picture_pc_3778f97aafe27793f3acff2af38a8d6f.png?width=1200)

Observed: a wooden writing desk with a chair, bookshelves along the rear wall, a sofa and coffee table beside the desk, plants, and partitions separating neighboring areas. The cutaway camera keeps the desk and lounge readable together. The furniture is ornate and library themed; no computer workstation is established by this image.

BlueOffice role after user clarification: optional independent office for a main secretary agent. Retain desk-plus-lounge zoning as a private-office reference; its ornate/library furniture is not the default modern shared-office style.

## Desk layout and room framing

Creator: calice. [Furniture placement guide](https://note.com/calicenon/n/n503250e23350), published 2025-08-24. The author includes this game preset image as a placement example.

![Abydos classroom café preset](https://assets.st-note.com/production/uploads/images/206496515/picture_pc_dbc02f20fa3e75c07501932953f66f20.png?width=1200)

Observed: rows of desks/chairs, pale walls, windows, lockers, partitions, and clear circulation. The image is a preset preview inside game UI. It is classroom themed, not a computer office.

BlueOffice role after user clarification: later classroom-like alternate world, deferred until office mode is good enough. General camera/readability observations remain useful, but do not carry classroom desks or a classroom preset into v1.
