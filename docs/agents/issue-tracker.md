# Issue tracker

This project uses GitHub Issues at `kriss-spy/blueoffice`. Read current acceptance criteria with `gh issue view NUMBER --json title,body,state`. The 21 initial tickets reference `docs/PRD.md`, `docs/IMPLEMENTATION-PLAN.md` and `docs/decisions/0001-local-office-architecture.md`.

Keep open tickets authoritative. Link implementation and evidence in pull requests. Do not claim visual or runtime acceptance from source inspection alone. `docs/STATUS.md` is an implementation ledger, not a replacement for ticket acceptance criteria.
