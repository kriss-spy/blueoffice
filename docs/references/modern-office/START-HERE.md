# Modern office reference capture

Status: reference capture, 2026-10-08. Target: BlueOffice, a local browser interface for Hermes. Source: user-supplied Blue Archive café recording and classroom screenshot; game edition/build and original showcase author are unknown. Scope: interior presentation, not reconstruction of café economy or game mechanics.

Read [design brief](DESIGN.md), then [evidence and asset manifest](evidence.json). Product behavior remains in [the experience specification](../../EXPERIENCE.md) and [PRD](../../PRD.md).

The selected direction is a modern open office with computer workstations and an actual café bar. The recording establishes workstation presentation and character/furniture interaction; the full open floor plan and café bar are user requirements, not visible evidence from this close-up. The classroom is a later alternate world, after office mode is good enough. A private study may suit a main secretary agent but is not the default office.

First visual milestone: one intended character seated at a modern computer workstation, visible status marker, a simple café counter in the shared room, and working side chat under the default 2.5D camera. Verify seated alignment and genuine agent status independently.

No runnable specimen was produced: this session is for planning documents. The earlier homepage concept illustrates navigation but predates this reference and does not validate the revised furniture, seated poses, materials, or café bar. The PNGs are reference-only; no character/furniture model was extracted.

## Acceptance for the eventual rendered slice

- Modern computer desks read as an open workplace, with shared circulation and low visual barriers (U01).
- A café counter, coffee equipment, and bar seating are recognizable from the default camera (U01). A sofa alone does not meet this requirement.
- Seated characters align with desks/chairs and preserve face/halo visibility (V01).
- Question markers reflect exact Hermes requests; game reaction symbols do not establish agent semantics.
- Camera preserves character/furniture scale relationships without claiming a measured projection or angle (V01).
- Classroom implementation starts only after the user accepts office mode as good enough (U03).

These checks have not been run on an application. Exact models/clips, materials, camera calibration, café furniture sourcing, motion durations, and audio remain unverified.
